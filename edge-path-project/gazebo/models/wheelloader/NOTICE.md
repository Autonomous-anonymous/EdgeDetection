# Wheel-loader model attribution

This experimental Gazebo Harmonic model is derived from the
NUVE-LAB / Mevea WheelLoader source model.

The supplied project materials identify Copyright Mevea Ltd
2018–2021 and NUVE-LAB 2026 and describe the source as
GPL-3.0-or-later. See LICENSE.GPL-3.0.

Visual and collision meshes were converted from the original
simulation assets. Redistribution rights for any third-party
geometry must be verified before public distribution.

This is a simplified SIL vehicle model, not a calibrated
hydraulic or vehicle-dynamics implementation.
